# Ai123

一个面向个人使用的 AI 导航页项目。

> 项目宪法见 `CONSTITUTION.md`。生产部署唯一准则：`GitHub -> Vercel 自动部署`。

在线版本使用 `Vercel` 部署，适合作为你的浏览器起始页或常用 AI 工具入口页。页面设计参考了 `hotai.tools` 的极简导航结构，并基于 `Next.js` 重新实现，方便后续继续扩展。

## 项目定位

这个项目解决的是一个很具体的问题：

- 常用网站分散在浏览器收藏夹里
- 换电脑后不一定能及时同步
- 想要一个自己可控、打开即用的个人导航页

当前版本优先解决：

- 统一入口
- 快速访问
- 分类浏览
- 本地自定义
- 快速部署上线

## 功能特性

- 参考 `hotai.tools` 的卡片式导航布局
- 内置一组常见 AI 工具默认链接
- 支持分类筛选
- 支持关键词搜索
- 支持自定义新增网站
- 支持删除自定义网站
- 支持本地拖拽排序
- 支持浏览器本地存储保存布局和自定义数据
- 支持一键部署到 `Vercel`

## 技术栈

- `Next.js 16`
- `React 19`
- 原生 `CSS`
- 浏览器 `localStorage`

## 本地开发

安装依赖：

```bash
pnpm install
```

启动开发环境：

```bash
pnpm dev
```

默认访问地址：

```bash
http://localhost:3000
```

生产构建：

```bash
pnpm build
pnpm start
```

## 部署方式

本项目可以直接导入 `Vercel`：

1. 将仓库推送到 GitHub
2. 在 Vercel 中选择 `Add New -> Project`
3. 导入当前仓库
4. 保持默认 `Next.js` 构建配置
5. 点击 `Deploy`

如果你已经绑定了自定义域名，只要后续继续向 `main` 分支推送代码，Vercel 就会自动重新部署。

### 部署宪法

- 生产环境只允许使用 `GitHub -> Vercel 自动部署`
- 任何生产发布都必须先提交到 Git，并推送到 `origin/main`
- 不将本地工作区直接作为常规生产发布源
- 非紧急情况下，不使用 `vercel --prod` 作为发布流程

## 数据说明

当前版本不依赖数据库。

所有“自定义添加”的网站和排序信息都保存在浏览器本地：

- 不需要注册账号
- 不需要后端服务
- 打开速度快
- 适合个人单用户使用

这也意味着：

- 换浏览器或清空缓存后，本地自定义数据不会自动同步
- 默认内置的链接仍然会保留

如果后续需要跨设备同步，可以再接入数据库服务。
